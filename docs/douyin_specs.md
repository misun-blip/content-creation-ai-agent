## 1. 平台概述

抖音是一款短视频社交平台，用户可以创作和分享短视频内容。平台注重内容的吸引力和传播性，对标题、正文、标签等有特定的格式要求。

---

## 2. 格式规范详情

### 2.1 标题规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **长度限制** | 最多30字符 | 超过部分会被截断 |
| **Emoji支持** | 支持 | 可使用emoji增强吸引力 |
| **特殊要求** | 需要吸引眼球 | 标题是用户点击的第一要素 |
| **建议** | 使用疑问句、感叹句、数字 | 提高点击率 |

**标题示例**:
- ✅ 好用！这3个技巧让视频爆火
- ✅ 90%的人都不知道的秘密
- ✅ 5分钟学会做这个
- ❌ 这是一段很长的标题，超过了30个字符的限制

---

### 2.2 正文规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **总长度限制** | 最多2000字符 | 超过部分可能无法显示 |
| **段落长度** | 每段不超过500字符 | 便于用户阅读 |
| **分段要求** | 建议分段显示 | 提高可读性 |
| **Emoji支持** | 支持 | 可在正文中使用emoji |
| **特殊要求** | 第一段为钩子 | 吸引用户停留观看 |

**正文结构建议**:
```
第一段（钩子）：用疑问句或悬念吸引注意力
第二段（内容）：详细介绍内容
第三段（价值）：提供实用价值
第四段（互动）：引导用户评论、点赞
```

**正文示例**:
```
你还在为视频没人看发愁吗？今天分享3个让视频爆火的技巧！

第一个技巧：选择热门话题。关注抖音热榜，结合自己的内容创作。

第二个技巧：优化封面和标题。封面要清晰，标题要吸引人。

第三个技巧：保持更新频率。每天至少发布一条视频，保持活跃度。

试试看，你的视频一定会火！记得点赞关注哦！
```

---

### 2.3 标签规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **数量限制** | 最多5个标签 | 超过部分会被忽略 |
| **标签格式** | #标签名 | 必须以#开头 |
| **标签长度** | 每个标签建议10字符以内 | 便于展示 |
| **特殊要求** | 与内容相关 | 提高推荐准确性 |

**标签选择建议**:
- 选择热门标签：#热门 #推荐 #上热门
- 选择垂直领域标签：#美食 #旅行 #科技
- 选择内容相关标签：#教程 #分享 #干货

**标签示例**:
- ✅ #热门 #美食 #教程 #分享 #干货
- ❌ #标签1 #标签2 #标签3 #标签4 #标签5 #标签6（超过5个）

---

### 2.4 封面规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **封面比例** | 9:16 | 竖屏高清图片 |
| **分辨率** | 建议1080x1920 | 保证清晰度 |
| **格式** | JPG、PNG | 支持常见图片格式 |
| **大小** | 建议5MB以内 | 保证加载速度 |
| **内容要求** | 清晰、吸引人 | 提高点击率 |

**封面设计建议**:
- 使用高对比度色彩
- 添加醒目的文字说明
- 保持画面简洁
- 突出视频主题

---

### 2.5 特殊要求

#### 2.5.1 标题要求
- 需要吸引眼球，激发用户好奇心
- 可使用emoji增强视觉效果
- 避免使用夸大其词的表述
- 与视频内容保持一致

#### 2.5.2 正文要求
- 第一段为钩子，吸引用户停留
- 内容要有价值，提供实用信息
- 语言简洁明了，避免冗长
- 适当使用emoji增加趣味性

#### 2.5.3 标签要求
- 标签需要与内容相关
- 选择热门标签提高曝光
- 避免使用无关标签
- 合理搭配热门标签和垂直标签

## 3. 最佳实践

### 3.1 标题优化技巧
1. **使用数字**: "3个技巧"、"5分钟学会"
2. **制造悬念**: "90%的人都不知道"
3. **提问式**: "你还在为这个发愁吗？"
4. **强调价值**: "超实用"、"必看"

### 3.2 正文写作技巧
1. **开头钩子**: 用疑问句或悬念吸引注意力
2. **结构清晰**: 分段明确，每段一个重点
3. **提供价值**: 给用户实用的信息或技巧
4. **引导互动**: 鼓励用户评论、点赞、关注

### 3.3 标签使用技巧
1. **组合使用**: 热门标签 + 垂直标签 + 内容标签
2. **数量适中**: 选择3-5个最相关的标签
3. **保持相关**: 标签必须与内容相关
4. **定期更新**: 关注热门标签变化

## 4. 常见问题

### Q1: 标题超过30字符会怎样？
A: 标题会被自动截断，只显示前30个字符，影响用户理解。

### Q2: 正文可以分段显示吗？
A: 可以，建议每段不超过500字符，提高可读性。

### Q3: 标签超过5个会怎样？
A: 只会保留前5个标签，多余的标签会被忽略。

### Q4: 封面比例必须是9:16吗？
A: 是的，9:16是抖音推荐的竖屏比例，能获得最佳展示效果。

### Q5: 可以在标题和正文中使用emoji吗？
A: 可以，抖音支持emoji使用，适当使用可以增强吸引力。
