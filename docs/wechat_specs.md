## 1. 平台概述

微信视频号是微信推出的短视频平台，用户可以创作和分享短视频内容。平台注重内容的简洁性和专业性，对标题、描述等有特定的格式要求。

---

## 2. 格式规范详情

### 2.1 标题规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **长度限制** | 最多30字符 | 超过部分会被截断 |
| **Emoji支持** | 不支持 | 不建议使用emoji |
| **特殊要求** | 需要简洁明了 | 标题要准确概括内容 |
| **建议** | 使用简洁、专业的表述 | 提高专业性 |

**标题示例**:
- ✅ 如何快速学习视频剪辑
- ✅ 3个提升工作效率的方法
- ✅ 2024年最新科技趋势
- ❌ 这是一段很长的标题，超过了30个字符的限制
- ❌ ✨超好用！这个太棒了（不推荐使用emoji）

---

### 2.2 描述规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **长度限制** | 最多200字符 | 超过部分会被截断 |
| **段落要求** | 不分段 | 整体显示 |
| **Emoji支持** | 不支持 | 不建议使用emoji |
| **特殊要求** | 需要概括内容要点 | 提供内容概要 |

**描述写作建议**:
- 简洁概括视频内容
- 突出视频的价值点
- 提供必要的背景信息
- 避免冗余表述

**描述示例**:
- ✅ 本视频介绍3个快速学习视频剪辑的方法，适合初学者，帮助你快速入门。
- ❌ 本视频介绍3个快速学习视频剪辑的方法，这些方法非常实用，适合初学者，帮助你快速入门，一定要看哦！（超过200字符）
- ❌ ✨本视频介绍3个方法🎯（不推荐使用emoji）

---

### 2.3 标签规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **数量限制** | 不支持标签 | 微信视频号暂不支持标签功能 |
| **格式** | - | - |
| **特殊要求** | - | - |

**说明**: 微信视频号目前不支持标签功能，因此在适配时需要忽略标签。

---

### 2.4 封面规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **封面比例** | 16:9 | 横屏高清图片 |
| **分辨率** | 建议1920x1080 | 保证清晰度 |
| **格式** | JPG、PNG | 支持常见图片格式 |
| **大小** | 建议5MB以内 | 保证加载速度 |
| **内容要求** | 清晰、专业、高质量 | 提高点击率 |

**封面设计建议**:
- 使用高清晰度的图片
- 保持画面简洁专业
- 突出视频主题
- 避免过度装饰

---

### 2.5 特殊要求

#### 2.5.1 标题要求
- 标题需要简洁明了，准确概括内容
- 不建议使用emoji
- 避免使用夸大其词的表述
- 与视频内容保持一致

#### 2.5.2 描述要求
- 描述需要概括内容要点
- 提供必要的背景信息
- 不建议使用emoji
- 语言简洁专业

#### 2.5.3 封面要求
- 封面需要高清清晰
- 保持画面简洁专业
- 突出视频主题
- 避免过度装饰

## 4. 常见问题

### Q1: 标题超过30字符会怎样？
A: 标题会被自动截断，只显示前30个字符，影响用户理解。

### Q2: 描述可以分段显示吗？
A: 不可以，微信视频号描述不分段，整体显示。

### Q3: 微信视频号支持标签吗？
A: 不支持，微信视频号目前暂不支持标签功能。

### Q4: 封面比例必须是16:9吗？
A: 是的，16:9是微信视频号推荐的横屏比例，能获得最佳展示效果。

### Q5: 可以在标题和描述中使用emoji吗？
A: 不建议，微信视频号不支持emoji，使用emoji可能影响显示效果。
