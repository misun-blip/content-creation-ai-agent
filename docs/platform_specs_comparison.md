## 3. 关键差异分析

### 3.1 标题差异

| 平台 | 特点 | 适配建议 |
|------|------|---------|
| **抖音** | 30字符，支持emoji，需要吸引眼球 | 使用疑问句、感叹句、数字，适当使用emoji |
| **小红书** | 20字符，支持emoji，需要简洁有力 | 使用emoji、数字、关键词，控制在20字符以内 |
| **微信视频号** | 30字符，不支持emoji，需要简洁明了 | 使用简洁、专业的表述，避免使用emoji |

### 3.2 正文/描述差异

| 平台 | 特点 | 适配建议 |
|------|------|---------|
| **抖音** | 2000字符，分段显示，支持emoji | 第一段为钩子，每段不超过500字符，适当使用emoji |
| **小红书** | 1000字符，emoji分隔，支持emoji | 使用emoji分隔段落，每段不超过300字符 |
| **微信视频号** | 200字符，不分段，不支持emoji | 概括内容要点，控制在200字符以内，避免emoji |

### 3.3 标签差异

| 平台 | 特点 | 适配建议 |
|------|------|---------|
| **抖音** | 最多5个标签，格式#标签名 | 选择5个最相关的标签，格式化为#标签名 |
| **小红书** | 最多10个标签，格式#标签名 | 选择10个最相关的标签，格式化为#标签名 |
| **微信视频号** | 不支持标签 | 忽略标签，不添加标签功能 |

### 3.4 封面差异

| 平台 | 特点 | 适配建议 |
|------|------|---------|
| **抖音** | 9:16竖屏 | 使用9:16比例的竖屏高清图片 |
| **小红书** | 3:4竖屏 | 使用3:4比例的竖屏高清图片 |
| **微信视频号** | 16:9横屏 | 使用16:9比例的横屏高清图片 |

## 4. 适配策略

### 4.1 通用适配原则

1. **标题适配**:
   - 抖音：30字符，支持emoji，吸引眼球
   - 小红书：20字符，支持emoji，简洁有力
   - 微信视频号：30字符，不支持emoji，简洁明了

2. **正文/描述适配**:
   - 抖音：2000字符，分段显示，支持emoji
   - 小红书：1000字符，emoji分隔，支持emoji
   - 微信视频号：200字符，不分段，不支持emoji

3. **标签适配**:
   - 抖音：最多5个标签，格式化为#标签名
   - 小红书：最多10个标签，格式化为#标签名
   - 微信视频号：忽略标签

4. **封面适配**:
   - 抖音：9:16竖屏
   - 小红书：3:4竖屏
   - 微信视频号：16:9横屏

### 4.2 智能适配建议

1. **自动截断**: 超过长度限制的内容自动截断，并提示用户
2. **自动分段**: 根据平台要求自动分段内容
3. **emoji处理**: 根据平台支持情况自动添加或移除emoji
4. **标签格式化**: 自动将标签格式化为平台要求的格式
5. **封面比例**: 根据平台要求调整封面比例
