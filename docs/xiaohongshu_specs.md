## 1. 平台概述

小红书是一个生活方式分享社区，用户可以分享购物心得、生活技巧、旅行攻略等内容。平台注重内容的实用性和美观度，对笔记格式有特定的要求。

---

## 2. 格式规范详情

### 2.1 标题规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **长度限制** | 最多20字符 | 超过部分会被截断 |
| **Emoji支持** | 支持 | 可使用emoji增强吸引力 |
| **特殊要求** | 需要简洁有力 | 标题要突出重点 |
| **建议** | 使用emoji、数字、关键词 | 提高点击率 |

**标题示例**:
- ✅ 3个超好用的小技巧
- ✅ 必看！这个太实用了
- ✅ 亲测有效！强烈推荐
- ❌ 这是一段很长的标题，超过了20个字符的限制

---

### 2.2 正文规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **总长度限制** | 最多1000字符 | 超过部分可能无法显示 |
| **段落长度** | 每段不超过300字符 | 便于用户阅读 |
| **分段要求** | 必须分段清晰 | 使用emoji分隔 |
| **Emoji支持** | 支持 | 强烈建议使用emoji |
| **特殊要求** | 使用emoji分隔段落 | 提高可读性 |

**正文结构建议**:
```
📌 第一段：介绍主题，吸引注意力

✨ 第二段：详细内容，提供价值

💡 第三段：实用技巧，增加实用性

🎯 第四段：总结要点，强化记忆

🔥 第五段：引导互动，鼓励收藏点赞
```

**正文示例**:
```
📌 今天分享3个超好用的生活小技巧，亲测有效！

✨ 第一个技巧：牙膏去除茶渍。用牙膏擦拭茶杯，轻松去除茶渍。

💡 第二个技巧：保鲜膜保护遥控器。用保鲜膜包裹遥控器，防止灰尘。

🎯 第三个技巧：橡皮擦清洁白鞋。用橡皮擦擦拭白鞋污渍，效果超好。

🔥 这3个技巧简单实用，快试试看！记得收藏点赞哦！
```

### 2.3 标签规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **数量限制** | 最多10个标签 | 超过部分会被忽略 |
| **标签格式** | #标签名 | 必须以#开头 |
| **标签长度** | 每个标签建议10字符以内 | 便于展示 |
| **特殊要求** | 覆盖主要关键词 | 提高推荐准确性 |

**标签选择建议**:
- 选择热门标签：#热门 #推荐 #种草
- 选择垂直领域标签：#生活小技巧 #好物分享 #日常
- 选择内容相关标签：#实用 #干货 #必看

**标签示例**:
- ✅ #热门 #生活小技巧 #好物分享 #实用 #干货 #种草 #日常
- ❌ #标签1 #标签2 #标签3 #标签4 #标签5 #标签6 #标签7 #标签8 #标签9 #标签10 #标签11（超过10个）

---

### 2.4 封面规范

| 规范项 | 要求 | 说明 |
|--------|------|------|
| **封面比例** | 3:4 | 竖屏高清图片 |
| **分辨率** | 建议1080x1440 | 保证清晰度 |
| **格式** | JPG、PNG | 支持常见图片格式 |
| **大小** | 建议5MB以内 | 保证加载速度 |
| **内容要求** | 清晰、美观、吸引人 | 提高点击率 |

**封面设计建议**:
- 使用明亮、清新的色彩
- 添加简洁的文字说明
- 突出产品或主题
- 保持画面简洁美观

---

### 2.5 特殊要求

#### 2.5.1 标题要求
- 标题需要简洁有力，突出重点
- 可使用emoji增强视觉效果
- 避免使用夸大其词的表述
- 与笔记内容保持一致

#### 2.5.2 正文要求
- 正文需要分段清晰，使用emoji分隔
- 内容要有价值，提供实用信息
- 语言简洁明了，避免冗长
- 强烈建议使用emoji增加趣味性

#### 2.5.3 标签要求
- 标签需要覆盖主要关键词
- 选择热门标签提高曝光
- 避免使用无关标签
- 合理搭配热门标签和垂直标签

## 3. 最佳实践

### 3.1 标题优化技巧
1. **使用emoji**: "✨3个技巧"、"🔥必看"
2. **使用数字**: "3个技巧"、"5分钟学会"
3. **强调价值**: "超实用"、"亲测有效"
4. **简洁有力**: 控制在20字符以内

### 3.2 正文写作技巧
1. **emoji分隔**: 每段使用emoji开头
2. **结构清晰**: 分段明确，每段一个重点
3. **提供价值**: 给用户实用的信息或技巧
4. **引导互动**: 鼓励用户收藏、点赞、评论

### 3.3 标签使用技巧
1. **覆盖关键词**: 选择与内容相关的关键词
2. **组合使用**: 热门标签 + 垂直标签 + 内容标签
3. **数量适中**: 选择5-10个最相关的标签
4. **定期更新**: 关注热门标签变化

## 4. 常见问题

### Q1: 标题超过20字符会怎样？
A: 标题会被自动截断，只显示前20个字符，影响用户理解。

### Q2: 正文必须使用emoji分隔吗？
A: 强烈建议使用emoji分隔，可以提高可读性和吸引力。

### Q3: 标签超过10个会怎样？
A: 只会保留前10个标签，多余的标签会被忽略。

### Q4: 封面比例必须是3:4吗？
A: 是的，3:4是小红书推荐的竖屏比例，能获得最佳展示效果。

### Q5: 可以在标题和正文中使用emoji吗？
A: 可以，小红书支持emoji使用，强烈建议适当使用以增强吸引力。
