# 内容创作AI-Agent 前端项目

## 项目简介

本项目是一个面向流媒体/自媒体营销的内容创作AI-Agent前端系统，基于Vue 3 + Element Plus构建，提供直观的数据可视化和创作管理功能。

## 技术栈

- **框架**: Vue 3 + Composition API
- **UI库**: Element Plus
- **数据可视化**: ECharts
- **路由**: Vue Router 4
- **状态管理**: Pinia
- **HTTP请求**: Axios
- **构建工具**: Vite
- **样式预处理器**: Sass

## 已实现功能

- **创作趋势图表**: 折线图展示12个月的创作数据

- **统计卡片**: 显示总素材数、创作记录等关键指标

- **账号安全设置**: 密码修改等安全相关功能

### 3. 认证页面 (Login/Register)
- **登录功能**: 支持用户名/密码登录，集成mock数据

## 运行项目

### 环境要求
- Node.js 16.0 或更高版本
- npm 7.0 或更高版本

### 安装依赖

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install
```

### 启动开发服务器

```bash
npm run dev
```

开发服务器启动后，会在控制台显示访问地址，通常为 `http://localhost:3003/`

### 构建生产版本

```bash
npm run build
```

构建产物会生成在 `dist` 目录中，可用于部署到生产环境。

## 登录说明

由于后端API尚未开发完成，系统集成了mock数据功能：

1. 打开登录页面 `http://localhost:3003/login`
2. 输入任意用户名和密码
3. 点击"登录"按钮即可进入系统

系统会自动生成mock用户数据和仪表盘数据，确保前端功能可以正常展示。

## API服务层

项目实现了完整的API服务层，包含以下特性：

- **统一的错误处理**: 当API调用失败时，自动返回mock数据
- **模块化设计**: 按功能模块划分API服务
- **类型安全**: 提供清晰的数据结构定义
- **可扩展性**: 易于集成真实后端API

## 响应式设计

项目采用响应式设计，适配不同屏幕尺寸：

- **桌面端**: 完整布局，多列显示
- **平板端**: 适当调整布局，保持良好的用户体验
- **移动端**: 单列布局，优化触摸交互

## 性能优化

- **路由懒加载**: 减少初始加载时间
- **组件按需引入**: 减小打包体积
- **图表按需渲染**: 优化大数据量图表的性能
- **缓存策略**: 合理缓存API响应数据

## 代码规范

项目遵循以下代码规范：

- **ESLint**: 确保代码质量和一致性
- **Prettier**: 自动格式化代码
- **Vue 3 Composition API最佳实践**: 合理使用setup语法糖
- **组件命名规范**: 使用PascalCase命名组件
- **变量命名规范**: 使用camelCase命名变量和函数

## 团队协作指南

### 分支管理

- **main**: 主分支，用于发布生产版本
- **dev**: 开发分支，用于集成各功能模块
- **feature/{功能名}**: 特性分支，用于开发具体功能

### 提交规范

建议使用以下提交信息格式：

```
<type>(<scope>): <subject>

<body>

<footer>
```

其中：
- **type**: feat(新功能)、fix(修复)、docs(文档)、style(样式)、refactor(重构)、test(测试)、chore(构建/依赖)
- **scope**: 功能模块名称
- **subject**: 提交的简要描述

### 开发流程

1. **克隆仓库**: `git clone <仓库地址>`
2. **创建分支**: `git checkout -b feature/{功能名}`
3. **安装依赖**: `npm install`
4. **开发功能**: 实现具体功能
5. **运行测试**: 确保功能正常
6. **提交代码**: `git add . && git commit -m "feat({功能名}): 实现{功能描述}"`
7. **推送分支**: `git push origin feature/{功能名}`
8. **创建PR**: 提交Pull Request进行代码审查
