## 1. 架构概述

本项目后端采用 **分层架构**，基于 Python FastAPI 框架构建，实现了 API 网关、认证中间件、数据库连接池、Redis 缓存、Docker 容器化部署等基础设施。

## 2. 技术选型与理由

| 技术 | 选型 | 理由 |
|------|------|------|
| Web 框架 | FastAPI | 异步高性能、自动 Swagger 文档、类型安全、Python 生态丰富 |
| ORM | SQLAlchemy 2.x | 成熟稳定、支持连接池、社区活跃 |
| 迁移工具 | Alembic | SQLAlchemy 官方配套、支持 autogenerate |
| 认证 | JWT (python-jose) | 无状态、前后端分离友好、移动端兼容 |
| 密码加密 | passlib + bcrypt | 行业标准、抗暴力破解 |
| 缓存 | Redis 6.0 | 高性能键值存储、支持过期策略 |
| 数据库 | MySQL 8.0 | 关系型数据、事务支持、团队熟悉 |
| 部署 | Docker + Nginx | 容器化隔离、反向代理、生产就绪 |
| 测试 | Pytest | Python 标准测试框架、丰富生态 |
| 配置管理 | pydantic-settings | 类型安全、.env 文件支持、自动验证 |

## 4. 核心模块设计

### 4.1 API 网关 (`main.py`)

- **请求日志中间件**：记录每个请求的方法、路径、状态码、耗时
- **全局异常处理**：统一捕获 HTTPException / ValidationError / 未知异常，返回 `{code, message}` 格式
- **CORS 配置**：支持前端跨域请求
- **路由注册**：延迟导入，避免启动时依赖缺失导致崩溃

### 4.2 认证机制 (`security.py` + `deps.py`)

- **JWT 令牌**：使用 HS256 算法签发，包含 `sub`（用户名）和 `exp`（过期时间）
- **密码安全**：bcrypt 哈希存储，不可逆
- **依赖注入**：`get_current_user` 从请求头提取 token → 解码 → 查库验证

### 4.3 数据库连接池 (`database.py`)

- **MySQL 模式**：pool_size=10, max_overflow=20, pool_recycle=1800s
- **自动切换**：根据 DATABASE_URL 前缀自动选择

### 4.4 Redis 缓存 (`redis_client.py`)

- **单例模式**：全局共享连接
- **优雅降级**：Redis 不可用时返回 None，不阻塞业务
- **操作接口**：cache_get / cache_set / cache_delete / cache_clear_pattern

### 4.5 统一响应格式 (`response.py` + `common.py`)

所有接口统一返回：
```json
{
  "code": 200,
  "message": "成功",
  "data": {}
}
```

分页接口返回：
```json
{
  "code": 200,
  "message": "成功",
  "data": {
    "items": [],
    "total": 100,
    "page": 1,
    "pageSize": 10,
    "hasNext": true
  }
}
```

## 6. 安全设计

| 安全措施 | 实现方式 |
|----------|----------|
| 认证 | JWT Bearer Token |
| 密码存储 | bcrypt 哈希 |
| SQL 注入防护 | SQLAlchemy ORM 参数化查询 |
| CSRF 防护 | JWT 无状态认证（天然抗 CSRF） |
| XSS 防护 | JSON API（不渲染 HTML） |
| 速率限制 | Nginx limit_req_zone 30r/s |
| 容器安全 | 非 root 用户运行 |

## 7. 团队协作指南

### 新增 Model 步骤

1. 在 `app/models/` 下创建模型文件（继承 `Base`）
2. 在 `alembic/env.py` 中添加 import
3. 运行 `alembic revision --autogenerate -m "描述"`
4. 运行 `alembic upgrade head`

### 新增 API 步骤

1. 在 `app/api/v1/` 下对应路由文件中添加端点
2. 使用 `from app.utils.response import success, paginated` 返回统一格式
3. 需要认证的端点添加 `current_user: User = Depends(deps.get_current_active_user)`
4. 在 Swagger (`/docs`) 中验证

### 使用 Redis 缓存

```python
from app.utils.redis_client import cache_get, cache_set

# 读取缓存
data = cache_get("materials:123")
if data is None:
    data = query_from_db()
    cache_set("materials:123", data, expire=300)
```
