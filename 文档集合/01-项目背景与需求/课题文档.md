## 1. 课题定位

定位为「轻量化、易上手的流媒体/自媒体营销内容辅助工具」，聚焦「营销素材语义智能检索、AI辅助内容生成（支持SSE流式输出与Few-Shot提示词工程）、多模态创作（文案+AI配图）、多平台格式一键适配（内置合规审计）、创作记录版本化管理与数据统计」等核心需求，适配主流内容平台的日常运营创作场景，重点验证 AI Agent 在营销垂直领域的落地应用能力。

## 2. 核心目标

1. 搭建基于 RAG（检索增强生成）语义搜索的营销内容素材库，支持文案模板、话题标签、图文配文等素材的多维度管理与智能检索。
2. 基于素材库上下文，通过 Few-Shot 提示词工程自动化实现选题推荐与文案生成，支持 SSE 流式逐字输出，提升人机协作体验。生成内容支持人工二次编辑优化。
3. 支持多模态内容创作，集成图像生成 API 实现文案配图一键生成。
4. 支持生成内容适配主流流媒体/自媒体平台（如抖音、小红书、微信视频号等），一键调整格式与排版，内置广告法违禁词合规审计。
5. 自动留存所有创作记录（含 AI 生成初稿、人工优化版本、发布平台），支持版本对比与按时间、平台类型、内容关键词查询。
6. 实现统计分析功能（每日产出量、关键词频次、平台分布、热点话题感知），数据可视化看板界面简洁易用。

## 3. 核心功能模块

| 模块名称 | 功能说明 |
| :--- | :--- |
| 用户认证模块 | 用户注册/登录、JWT认证、个人信息与头像管理、密码修改。 |
| 素材库管理模块 | 素材增删改查、分类与标签管理、文件上传（图片/视频）、基于RAG的语义智能检索。 |
| AI内容生成模块 | 基于Few-Shot Prompt的选题推荐、SSE流式文案生成、AI配图生成、内容质量与广告法合规评估。 |
| 平台适配模块 | 支持抖音/小红书/微信视频号一键格式适配，自动排版、Emoji装饰、标签格式化，内置违禁词审计与风险提示。 |
| 创作记录管理模块 | 自动留存创作记录，支持版本管理（AI初稿 vs 人工优化）、版本对比、多条件检索、Word/PDF导出。 |
| 统计分析与仪表盘模块 | 每日产出统计、关键词频次分析、平台分布图、热点话题感知、ECharts数据可视化看板。 |
