## 6. Postman 接口测试说明

Postman 集合位于 `tests/postman/content-creation-ai-agent.postman_collection.json`，覆盖认证、素材 CRUD、AI 生成、仪表盘共 20 个请求。

**导入并运行步骤**：
1. 打开 Postman → Import → 选择上述 JSON 文件
2. 修改 Collection Variables 中 `baseUrl`（默认 `http://localhost:8000`）
3. 先运行「认证模块 > 注册新用户」→「用户登录」，token 会自动写入变量
4. 点击 Collection 右键 → **Run Collection** → 按顺序执行全部请求
