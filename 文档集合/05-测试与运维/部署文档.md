## 2. 本地开发部署

### 2.1 安装依赖

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux/Mac
pip install -r requirements.txt
```

### 2.2 配置环境变量

复制 `.env.example` 为 `.env`，按需修改：

```env
DATABASE_URL=mysql+pymysql://root:content_ai_2024@localhost:3306/content_ai_agent
REDIS_URL=redis://localhost:6379/0
SECRET_KEY=your-secret-key-change-in-production
DEBUG=True
```

### 2.3 数据库迁移

```bash
# 生成迁移脚本
alembic revision --autogenerate -m "描述信息"

# 执行迁移
alembic upgrade head
```

### 2.4 启动服务

```bash
uvicorn app.main:app --reload --port 8000
```

访问 http://localhost:8000/docs 查看 API 文档。

## 3. Docker 部署

### 3.1 构建并启动所有服务

```bash
# 在项目根目录
docker compose build backend
docker compose up -d mysql redis backend
```

### 3.2 查看服务状态

```bash
docker compose ps
```

预期输出：
```
NAME                 STATUS                   PORTS
content_ai_backend   Up (healthy)             0.0.0.0:8000->8000/tcp
content_ai_mysql     Up (healthy)             3306/tcp
content_ai_redis     Up (healthy)             0.0.0.0:6379->6379/tcp
```

### 3.3 查看日志

```bash
docker compose logs backend       # 后端日志
docker compose logs -f backend    # 实时跟踪日志
```

### 3.4 停止服务

```bash
docker compose down               # 停止并移除容器
docker compose down -v            # 同时删除数据卷（清除数据库）
```

## 4. 生产环境部署

### 4.1 启动全部服务（含 Nginx）

```bash
docker compose up -d
```

### 4.2 Nginx 配置说明

| 路径 | 代理目标 | 说明 |
|------|----------|------|
| `/` | frontend:3000 | 前端页面 |
| `/api/` | backend:8000 | 后端 API |
| `/docs` | backend:8000 | Swagger 文档 |
| `/health` | backend:8000 | 健康检查 |

- API 限流：30 请求/秒/IP，burst=20
- Gzip 压缩：已启用
- 入口端口：80

### 4.3 生产环境注意事项

1. **修改 SECRET_KEY**：生产环境必须使用强随机密钥
2. **修改数据库密码**：替换 `docker-compose.yml` 中的默认密码
3. **关闭 DEBUG**：设置 `DEBUG=False`
4. **CORS 配置**：修改 `config.py` 中的 `CORS_ORIGINS` 为实际域名
5. **HTTPS**：建议在 Nginx 层配置 SSL 证书
