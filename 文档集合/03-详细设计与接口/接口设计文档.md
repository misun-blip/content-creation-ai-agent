## 1. 接口概述
本接口设计文档描述了"内容创作AI-Agent"项目的RESTful API接口规范，用于实现素材管理、AI内容生成、平台适配、创作记录和统计分析等功能。接口采用JSON格式传输数据，支持CORS跨域请求，使用JWT Token进行认证。
## 2. 接口设计原则
1. **RESTful风格**：使用标准的HTTP方法（GET/POST/PUT/DELETE）
2. **版本控制**：接口URL包含版本号（/api/v1/）
3. **统一响应格式**：所有接口返回统一的JSON格式
4. **错误处理**：标准化的错误码和错误信息
5. **安全性**：JWT Token认证，HTTPS传输
6. **文档化**：使用Swagger/OpenAPI规范
## 3. 认证机制
### 3.1 认证方式
- **JWT Token**：所有需要认证的接口需在请求头中添加Authorization字段
- **格式**：Bearer {token}
### 3.2 认证流程
1. 用户登录获取JWT Token
2. 在后续请求中携带Token
3. 服务器验证Token有效性
## 4. 数据格式规范
### 4.1 请求格式
```json
{
  "code": 200,

}
```
### 4.2 错误响应格式

## 5. 接口列表
### 5.1 素材库管理模块
#### 5.1.1 获取素材列表
- **URL**: `GET /api/v1/materials`
- **描述**: 获取素材列表，支持分页、关键词搜索以及按类型、分类、标签筛选
- **请求参数（Query）**:
  - `page`：页码，默认为 1
  - `pageSize`：每页数量，默认为 10
  - `keyword`：关键词，匹配素材名称与内容
  - `type`：素材类型（`template`/`image`/`video`/`audio`/`document`）
  - `categoryId`：分类 ID
  - `tag`：标签名称
- **响应**:
  ```json
  {
    "code": 200,
    "message": "成功",
    "data": {
      "items": [
        {
          "id": 1,
          "name": "营销模板1",
          "type": "template",
          "categoryId": 3,
          "content": "这是一段营销文案...",
          "tags": ["热点", "促销"],
          "createdAt": "2024-01-01T10:00:00Z"
        }
      ],
      "total": 100,
      "page": 1,
      "pageSize": 10,
      "hasNext": true
    }
  }
  ```
#### 5.1.2 创建素材
- **URL**: `POST /api/v1/materials`
- **描述**: 创建新的素材
- **请求体**:
  ```json
  {
    "name": "新营销模板",
    "type": "template",
    "categoryId": 3,
    "content": "这是一段新的营销文案...",
    "tags": ["热点", "促销"]
  }
  ```
- **响应**:
  ```json
  {
    "code": 200,
    "message": "创建成功",
    "data": {
      "id": 101
    }
  }
  ```
#### 5.1.3 更新素材
- **URL**: `PUT /api/v1/materials/{id}`
- **描述**: 更新指定素材
- **请求体**:
  ```json
  {
    "name": "更新后的营销模板",
    "type": "template",
    "categoryId": 5,
    "content": "更新后的营销文案...",
    "tags": ["热点", "促销", "新品"]
  }
  ```
- **响应**:
  ```json
  {
    "code": 200,
    "message": "更新成功"
  }
  ```
#### 5.1.4 删除素材
- **URL**: `DELETE /api/v1/materials/{id}`
- **描述**: 删除指定素材
- **响应**:
  ```json
  {
    "code": 200,
    "message": "删除成功"
  }
  ```

#### 5.1.5 获取热门标签
- **URL**: `GET /api/v1/tags/hot`
- **描述**: 获取按使用次数排序的热门标签列表
- **请求参数（Query）**:
  - `limit`：返回标签数量，默认 20
- **响应**:
  ```json
  {
    "code": 200,
    "message": "成功",
    "data": [
      {
        "name": "热点",
        "usageCount": 128
      }
    ]
  }
  ```
### 5.2 AI内容生成模块
#### 5.2.1 生成选题
- **URL**: `POST /api/v1/ai/topics`
- **描述**: 基于关键词生成选题
- **请求体**:
  ```json
  {
    "keywords": ["营销", "热点"],
    "platform": "douyin"
  }
  ```
- **响应**:
  ```json
  {
    "code": 200,
    "message": "生成成功",
    "data": {
      "topics": [
        "2024年营销热点趋势分析",
        "热点营销案例分析"
      ]
    }
  }
  ```
#### 5.2.2 生成文案
- **URL**: `POST /api/v1/ai/content`
- **描述**: 基于选题生成文案
- **请求体**:
  ```json
  {
    "topic": "2024年营销热点趋势分析",
    "platform": "douyin",
    "keywords": ["营销", "热点"]
  }
  ```
- **响应**:
  ```json
  {
    "code": 200,
    "message": "生成成功",
    "data": {
      "content": "2024年营销热点趋势分析...",
      "suggestions": ["增加互动环节", "优化标题"]
    }
  }
  ```

  ```json
    "data": {
      "formattedContent": "适配后的抖音格式内容...",
      "preview": "预览内容"
    }
  }
  ```

## 6. 错误码定义
| 错误码 | 描述 | HTTP状态码 |
|--------|------|-----------|
| 200 | 成功 | 200 |
| 400 | 参数错误 | 400 |
| 401 | 未授权 | 401 |
| 403 | 禁止访问 | 403 |
| 404 | 资源不存在 | 404 |
| 500 | 服务器内部错误 | 500 |
| 1001 | 素材不存在 | 400 |
| 1002 | 素材类型错误 | 400 |
| 2001 | AI服务不可用 | 500 |
| 2002 | 生成失败 | 500 |
| 3001 | 平台不支持 | 400 |
| 4001 | 记录不存在 | 400 |
| 5001 | 统计数据不存在 | 400 |
## 7. 安全规范
1. **HTTPS**：所有接口必须通过HTTPS访问
2. **CORS**：配置适当的CORS策略
3. **输入验证**：对所有输入参数进行严格验证
4. **SQL注入防护**：使用参数化查询
5. **XSS防护**：对输出内容进行HTML转义
6. **速率限制**：对API调用进行速率限制
