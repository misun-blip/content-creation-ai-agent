## 数据结构

### StatisticsDaily（日创作量统计）

|字段|类型|说明|
|---|---|---|
|date_str|string|日期，格式 `YYYY-MM-DD`|
|count|integer|当日创作篇数|
### StatisticsPlatform（平台分布统计）

|字段|类型|说明|
|---|---|---|
|platform|string|平台：douyin / xiaohongshu / wechat / bilibili / general / 未分类|
|count|integer|该平台创作篇数|
### StatisticsType（创作类型分布）

|字段|类型|说明|
|---|---|---|
|type|string|创作类型，为空时默认为文案|
|count|integer|该类型创作篇数|
### StatisticsKeyword（热门关键词）

|字段|类型|说明|
|---|---|---|
|keyword|string|关键词文本|
|count|integer|出现次数|

## 核心统计接口

### 1. 获取日创作量统计

获取指定时间范围内每日创作篇数，按日期升序。

#### 请求

`GET /api/v1/statistics/daily`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期，格式 YYYY-MM-DD|
|end_date|string|否|结束日期，格式 YYYY-MM-DD|
#### 响应示例

```JSON

{
  "code": 200,
  "message": "获取每日创作篇数成功",
  "data": {
    "2026-02-01": 3,
    "2026-02-02": 5
  }
}
```

---

### 2. 获取平台分布统计

获取各平台创作数量分布。

#### 请求

`GET /api/v1/statistics/platform`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期|
|end_date|string|否|结束日期|
#### 响应示例

```JSON

{
  "code": 200,
  "message": "获取平台分布成功",
  "data": [
    {
      "platform": "douyin",
      "count": 12
    },
    {
      "platform": "未分类",
      "count": 0
    }
  ]
}
```

---

### 3. 获取创作类型分布统计

按创作类型统计篇数，空类型默认为“文案”。

#### 请求

`GET /api/v1/statistics/type`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期|
|end_date|string|否|结束日期|
#### 响应示例

```JSON

{
  "code": 200,
  "message": "获取创作类型分布成功",
  "data": [
    {
      "type": "文案",
      "count": 20
    }
  ]
}
```

---

### 4. 获取热门关键词统计

提取标题+内容关键词，自动过滤无意义词，默认返回 Top3。

#### 请求

`GET /api/v1/statistics/keywords`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期|
|end_date|string|否|结束日期|
|top_n|int|否|默认 3，强制返回前3|
#### 响应示例

```JSON

{
  "code": 200,
  "message": "获取热门关键词成功",
  "data": [
    {
      "keyword": "科技产品",
      "count": 15
    },
    {
      "keyword": "营销",
      "count": 10
    },
    {
      "keyword": "短视频",
      "count": 8
    }
  ]
}
```

---

### 5. 获取总字数统计

统计所选时间段内所有内容真实总字数。

#### 请求

`GET /api/v1/statistics/total_words`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期|
|end_date|string|否|结束日期|
#### 响应示例

```JSON

{
  "code": 200,
  "message": "获取真实总字数成功",
  "data": 12580
}
```

---

### 6. 获取平均创作时长

空实现，返回固定兜底值。

#### 请求

`GET /api/v1/statistics/avg_time`

#### 响应示例

```JSON

{
  "code": 200,
  "message": "平均创作时长暂未统计",
  "data": 1
}
```

## 导出

### 1. 导出统计报告 CSV

导出总篇数、总字数、每日数据、平台分布。

#### 请求

`GET /api/v1/statistics/export_report`

#### Query 参数

|参数|类型|必填|说明|
|---|---|---|---|
|start_date|string|否|开始日期|
|end_date|string|否|结束日期|
#### 响应

返回 CSV 文件，自动下载。

文件名示例：`report_20260302123000.csv`
